# ManakSetu Application Screenshots

This directory stores visual assets and application screenshots referenced in [`README.md`](../README.md) and [`docs/`](../docs/).

## Screenshot Checklist & Capture Guide

To capture high-resolution screenshots for the repository:

| Filename | Route / URL | Recommended Screen State | Description |
| :--- | :--- | :--- | :--- |
| `landing-page.png` | `http://localhost:5173/` | Hero section, government badges, Quick Actions cards | Main portal landing page displaying BIS institutional branding and quick action pathways. |
| `analyzer.png` | `http://localhost:5173/analyze` | Input form with sample procurement requirement entered | The natural-language requirement submission interface with preset chip selectors. |
| `results.png` | `http://localhost:5173/analyze` | Analysis results cards, extracted entities pill badges, evidence breakdown | Recommendation output displaying primary applicable standard, confidence score, and grounded evidence. |
| `standard-detail.png` | `http://localhost:5173/standards/1` | Standard metadata header, scope text, normative relationships panel | Deep dive view of IS 2082:2018 showing certification status, technical specifications, and referenced safety standards. |
| `knowledge-graph.png` | `http://localhost:5173/knowledge-graph` | Full interactive graph canvas with nodes, relationship edges, and node detail sidebar | Visual knowledge graph demonstrating normative reference traversal between IS 2082, IS 302, and IS/IEC 60730. |
| `standards-hub.png` | `http://localhost:5173/standards` | Search bar, category filters, standards grid view | Directory catalogue listing active and superseded Indian Standards with status badges. |

### Capture Recommendations
- **Resolution:** Minimum `1920x1080` (1080p) or `1440x900` at 100% browser scaling.
- **Theme:** Default government theme (Navy blue header, clean white cards, slate borders).
- **Format:** Optimized PNG (`.png`).
